A5RT FrameworkALGO5THM / A5RT
PHILOSOPHY
PROTECT → QUALIFY → EXECUTE. Trading is about managing risk, following a process and letting probability work in your favour over time.
Core Principles
01
Capital preservation precedes opportunity
Protecting capital is the primary objective. No setup, however strong it appears, justifies abandoning defined risk rules.
02
Higher-timeframe context determines the environment
Multi-timeframe structural analysis determines whether a trading environment exists before any execution is considered.
03
Liquidity provides the location
Valid trade locations are defined by liquidity structure, not by price proximity to an arbitrary level.
04
Market structure provides confirmation
Confirmation comes from structure and momentum shifts on the execution timeframe, not from prediction.
05
Execution should be repeatable
Every element of the execution process — entry, stop, target, sizing — must be defined and reproducible.
06
Every trade becomes data
Outcomes are secondary to process quality. Each trade is a data point for continuous improvement.
System Architecture
HTF DIRECTIONAL BIAS
A5RT uses a proprietary higher-timeframe directional framework to establish market context before any execution is considered. The specific models and their conditions are part of the core A5RT IP.
EXECUTION — ARC (ASIA RANGE CIRCLE)
A proprietary intraday reference range built from defined market hours. Used exclusively within the London execution window. Validated on EURUSD and GBPUSD.
ARC operates within one of two proprietary contextual modes depending on the market conditions present at execution time. The rules governing this classification are part of the A5RT framework and are not publicly documented.

Hard Stop RulesZERO TOLERANCE
01
No trades outside A5RT qualification
Qualification criteria must be satisfied before entry. If the setup cannot be graded as qualified before execution, it is not taken.
DATA: Unqualified trades → negative expected value · 0% win rate in sample
02
No ARC re-entries after a failed first entry
ARC is session-scoped. A failed first entry consumes the context. No re-entry until the next session's ARC forms independently.
DATA: ARC R.ENTRY → 0/5 wins · −6.12R
03
Never delete a valid set limit order
A placed limit order on a valid A+ setup remains active until it triggers or the setup is structurally invalidated. Anxiety is not structural invalidation.
DATA: Documented missed opportunities including 1:20R and 1:49.91R
04
Maximum 2 trades per day
Two executed trades closes the session. No further entries regardless of setup quality or daily result.
DATA: Defined risk model · C3/C4 spiral mechanism
05
Defined daily stop
A defined daily drawdown threshold closes the session immediately when reached. No exceptions, no recovery attempts.
DATA: Defined risk model
